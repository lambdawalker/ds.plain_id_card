# Source and attribution

This is a browser adaptation of the drawing modules and country artwork in
[lambdawalker/python_lw_drawing_tools](https://github.com/lambdawalker/python_lw_drawing_tools),
reviewed at commit 8b95c05f4a8bfe62138a2a92b4d48dd5bf97b9a7.
The upstream MIT license is included as LICENSE.

The Voronoi fragment shader is adapted directly from draw/gradient/voronoid/paint.py.
Country SVG files are copied from lambdawalker/assets/img/country_shapes with their
original filenames. The upstream repository supplies these assets under its repository
license without separate per-country attribution.

HSLuv conversions use the hsluv npm package under its MIT license.
